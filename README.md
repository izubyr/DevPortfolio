# DevPortfolio

A personal portfolio website for Ibrahim Musa Zubairu, showcasing software development projects, services, skills, and contact information.

## Overview

This portfolio is a responsive single-page website built with HTML and CSS, designed to highlight:

- About section
- Skills and expertise
- Services offered
- Selected projects
- Contact and social links

## Tech Stack

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts
- Responsive web design

## Project Structure

- `index.html` — main portfolio page
- `styles.css` — styling and responsive layout
- `pics/` — images used in the portfolio

## Features

- Fixed top navigation bar
- Smooth scrolling
- Responsive mobile menu
- Modern card-based layout
- Project showcase cards
- Contact section with email and social links
- Clean, minimal, professional design

## Local Preview

Open `index.html` in a browser, or use a local web server such as:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
